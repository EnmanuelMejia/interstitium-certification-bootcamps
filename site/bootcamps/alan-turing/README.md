## What's covered

Computability, the Turing machine, Bletchley Park codebreaking, the Turing test, and morphogenesis — the foundational ideas of Alan Turing (1912-1954), taught as intellectual history and working concepts. This is an independent study course; it confers no certificate and claims no affiliation with any institution.
