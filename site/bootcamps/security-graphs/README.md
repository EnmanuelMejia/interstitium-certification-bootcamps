## What's covered

Operational use of security graphs: attack-path-driven patch prioritization, insider-threat detection via user-asset graphs, Zero Trust relationship policies, microsegmentation, blast-radius mapping for incident response, and graph-fed AI for predictive defense.

### Key points
- Patch priority comes from the graph, not the score alone: fix the flaw on the shortest path to what matters most.
- User-asset graphs surface insider misuse as anomalous relationships, not anomalous single events.
- Zero Trust is relationship enforcement: microsegmentation, relationship-based access control, and continuous verification all run on graphs.
- During incidents, the graph is the blast-radius map and the war-room common picture.
