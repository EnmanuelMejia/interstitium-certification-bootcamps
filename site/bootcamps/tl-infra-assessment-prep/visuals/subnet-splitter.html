How the math works: borrowing n bits from a /16 gives 2n subnets of size /(16+n). Each subnet: network = first address (never assignable) · broadcast = last address (never assignable) · usable hosts = 2host bits − 2. The subnet mask's binary 1s always count exactly the prefix length.
